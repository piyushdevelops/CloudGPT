# Our Days landing-page prototype

Mobile-first standalone product facade for the working name **Our Days**.

This prototype is intentionally isolated from Shopify and from `photobook-studio-mvp`. No remote theme files or store resources were changed. Its prices are positioning hypotheses, not approved selling prices.

Open `index.html` directly or serve this directory with a local HTTP server. The early-list form is deliberately local-only and sends no customer data.

## Implemented sections

- branded hero and phone-to-book explanation;
- three-step customer journey;
- interactive prompt categories;
- sample automatic book spread;
- three provisional plans;
- privacy principles;
- FAQ;
- early-access capture concept;
- mobile sticky conversion bar;
- reduced-motion treatment.
